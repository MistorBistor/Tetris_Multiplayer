# Zasoby (Resources)

Ten katalog zawiera zasoby używane w grze Tetris.

## Struktura

```
resources/
├── fonts/        # Czcionki (np. Arial.ttf, do wyświetlania tekstu)
├── textures/     # Tekstury (opcjonalnie, dla efektów wizualnych)
├── sounds/       # Efekty dźwiękowe (np. line-clear.wav, rotate.wav)
└── music/        # Muzyka w tle (np. tetris-theme.ogg)
```

## Uwagi

- Upewnij się, że wszystkie używane zasoby mają odpowiednią licencję
- Zalecane formaty:
  - Czcionki: `.ttf`
  - Dźwięki: `.wav` lub `.ogg`
  - Muzyka: `.ogg`
  - Tekstury: `.png`
